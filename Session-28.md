## Key Learnings

### 1. Introduction to Computer Vision
Computer Vision is a field of Artificial Intelligence that enables computers to interpret and understand visual information from images and videos. It helps machines identify objects, recognize patterns, and extract useful information from visual data.

### 2. Image Representation
Computers represent images as numerical data called pixels.

- **Grayscale Images:** Represent brightness using pixel values.
- **Color Images:** Commonly represented using three channels: Red, Green, and Blue (RGB).
- **Image Preprocessing:** Includes resizing, normalization, and converting images into suitable formats for a model.

### 3. Image Classification
Image classification identifies the main category of an image.

**Example:** Classifying an image as a cat, dog, car, or flower.

### 4. Object Detection
Object detection identifies objects within an image and determines their locations, usually using bounding boxes.

**Example:** Detecting cars, pedestrians, and traffic signs in a road image.

### 5. Convolutional Neural Networks (CNNs)
A CNN is a type of deep learning model widely used for image-related tasks.

Important components:
- **Convolutional Layer:** Extracts features such as edges and patterns.
- **Activation Function:** Introduces non-linearity into the network.
- **Pooling Layer:** Reduces the spatial dimensions of feature maps.
- **Fully Connected Layer:** Uses extracted features to produce predictions.

### 6. Applications of Computer Vision
- Facial recognition
- Medical image analysis
- Self-driving vehicles
- Security and surveillance
- Quality inspection in manufacturing
- Object detection in photographs and videos

## Common Python Tools
- `OpenCV` – Used for image processing and computer vision tasks.
- `Pillow` – Used to open, manipulate, and save images.
- `TensorFlow` – Supports deep learning and image classification.
- `PyTorch` – Used to build and train computer vision models.
- `NumPy` – Supports numerical operations on image arrays.

## Key Takeaways
- Computer Vision enables machines to interpret images and videos.
- Images are represented as numerical pixel values.
- Image classification assigns categories to images.
- Object detection identifies objects and their locations.
- CNNs automatically learn useful visual features.
- Computer Vision has applications in healthcare, transport, security, and manufacturing.
