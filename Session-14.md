## Key Learnings

- **Linear Regression:** A supervised learning algorithm used to predict continuous numerical values by finding a linear relationship between input features and the target.
- **Simple Linear Regression:** Uses one independent variable to predict an output.
- **Multiple Linear Regression:** Uses two or more independent variables to predict an output.
- **Model Training:** The algorithm learns the relationship between input features and target values from training data.
- **Prediction:** The trained model estimates output values for new inputs.
- **Model Evaluation:** Metrics such as MAE, MSE, RMSE, and R² Score help evaluate prediction performance.

## Important Formula

Linear Regression Equation:

y = mx + c

Where:
- y = Predicted output
- x = Input feature
- m = Slope of the line
- c = Intercept

## Common Python Tools
- `LinearRegression()` – Creates a linear regression model using Scikit-learn.
- `fit()` – Trains the model on the training data.
- `predict()` – Generates predictions for new inputs.
- `mean_absolute_error()` – Calculates the average absolute prediction error.
- `r2_score()` – Measures how well the model explains the variation in the target.

## Key Takeaways
- Linear Regression predicts continuous numerical values.
- Training data helps the model learn relationships between variables.
- Evaluation metrics help measure prediction accuracy.
- Linear Regression is useful for sales forecasting, house price prediction, and trend analysis.
