# Session 6: Data Collection and Dataset Understanding

## Topics Covered
- Introduction to data collection.
- Understanding datasets and their structure.
- Types of data and features.

## Key Learnings

- **Data Collection:** Gathering relevant information from sources such as CSV files, databases, APIs, and websites.
- **Dataset:** A collection of data organized into rows and columns.
- **Features:** Input variables used by a Machine Learning model to make predictions.
- **Labels:** The target values that a supervised learning model learns to predict.
- **Data Types:** Data can be numerical, categorical, text-based, or date/time data.
- **Dataset Exploration:** Examining the number of rows, columns, data types, and missing values before model training.

## Common Pandas Operations
- `head()` – Displays the first five rows by default.
- `shape` – Returns the number of rows and columns.
- `info()` – Shows column names, data types, and non-null counts.
- `describe()` – Provides statistical summaries of numerical columns.
- `isnull().sum()` – Counts missing values in each column.

## Key Takeaways
- Good-quality data is essential for building reliable ML models.
- Understanding features and labels helps define the learning problem.
- Initial dataset exploration helps identify missing values and data issues.
- Pandas provides useful functions for inspecting datasets.

## Summary
Learned how data is collected and organized, how to identify features and labels, and how to explore datasets using Pandas before applying Machine Learning algorithms.
