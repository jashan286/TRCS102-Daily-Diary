## Key Learnings

- **Clustering:** An unsupervised Machine Learning technique that groups similar data points together.
- **Unsupervised Learning:** Learns patterns from unlabelled data without predefined target values.
- **Similarity:** Data points are grouped based on similarities in their features.
- **K-Means Clustering:** Divides data into a predefined number of clusters.
- **Hierarchical Clustering:** Creates a hierarchy of clusters that can be represented using a dendrogram.
- **DBSCAN:** Groups closely packed data points and identifies noise or outliers.

## Applications
- Customer segmentation.
- Document grouping.
- Image segmentation.
- Anomaly detection.
- Grouping similar products.

## Common Python Tools
- `KMeans()` – Performs K-Means clustering.
- `AgglomerativeClustering()` – Performs hierarchical clustering.
- `DBSCAN()` – Identifies clusters based on data density.
- `fit_predict()` – Fits a clustering model and returns cluster labels.

## Key Takeaways
- Clustering discovers hidden patterns in unlabelled data.
- Similar data points are grouped into clusters.
- Different algorithms are suitable for different data structures.
- Feature scaling can improve clustering results when distance calculations are used.
