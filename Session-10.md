# Session 10: Basic Statistics for Machine Learning

## Topics Covered
- Mean, Median, and Mode.
- Variance and Standard Deviation.
- Range and Percentiles.
- Understanding data distribution.

## Key Learnings

- **Mean:** The average of all values in a dataset.
- **Median:** The middle value when data is arranged in ascending or descending order.
- **Mode:** The most frequently occurring value in a dataset.
- **Range:** The difference between the maximum and minimum values.
- **Variance:** Measures how far data values spread from the mean.
- **Standard Deviation:** Measures the typical spread of data values around the mean.
- **Percentiles:** Indicate the position below which a specified percentage of observations falls.

## Common Python Tools
- `mean()` – Calculates the average.
- `median()` – Finds the middle value.
- `mode()` – Finds the most frequent value.
- `np.var()` – Calculates variance.
- `np.std()` – Calculates standard deviation.
- `df.describe()` – Provides a statistical summary of a dataset.

## Key Takeaways
- Statistics helps summarize and understand datasets.
- Mean, median, and mode describe the central tendency of data.
- Variance and standard deviation measure data variability.
- Statistical analysis supports Exploratory Data Analysis and Machine Learning.
