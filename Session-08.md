# Session 8: Data Preprocessing and Feature Scaling

## Topics Covered
- Introduction to data preprocessing.
- Encoding categorical variables.
- Feature scaling and normalization.
- Splitting data into training and testing sets.

## Key Learnings

- **Data Preprocessing:** Preparing raw data for Machine Learning by cleaning and transforming it.
- **Encoding:** Converting categorical values into numerical form using techniques such as Label Encoding and One-Hot Encoding.
- **Feature Scaling:** Bringing numerical features to comparable scales so that differences in their ranges do not unfairly affect certain algorithms.
- **Normalization:** Scaling values to a specified range, commonly between 0 and 1.
- **Standardization:** Transforming values to have a mean of 0 and a standard deviation of 1.
- **Train-Test Split:** Dividing a dataset into training and testing sets to evaluate model performance on unseen data.

## Common Python Tools
- `LabelEncoder` – Encodes categorical labels as numbers.
- `OneHotEncoder` – Creates binary columns for categories.
- `StandardScaler` – Standardizes numerical features.
- `MinMaxScaler` – Scales numerical features to a specified range.
- `train_test_split()` – Splits data into training and testing sets.

## Key Takeaways
- Preprocessing improves data quality and prepares it for model training.
- Encoding converts categorical data into a suitable numerical format.
- Feature scaling is important for algorithms sensitive to feature magnitudes.
- Test data should remain separate from training data to evaluate generalization fairly.

## Summary
Learned essential data preprocessing techniques, including categorical encoding, feature scaling, and train-test splitting, to prepare datasets for Machine Learning.
