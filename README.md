# AI/ML Training Daily Diary

## Overview
This repository documents my daily learning journey during the AI/ML training program. It contains session-wise notes, important concepts, key learnings, Python tools, and summaries of the topics covered throughout the training.

The training focuses on understanding Artificial Intelligence (AI), Machine Learning (ML), data preprocessing, machine learning algorithms, deep learning, and real-world applications.

## Training Objectives
- Understand the fundamentals of Artificial Intelligence and Machine Learning.
- Learn data collection, cleaning, preprocessing, and visualization.
- Explore machine learning algorithms for regression, classification, and clustering.
- Understand model evaluation and performance metrics.
- Learn the fundamentals of neural networks and deep learning.
- Explore Computer Vision and Natural Language Processing (NLP).
- Understand the basics of model deployment and real-world AI/ML applications.

## Topics Covered
- Introduction to AI, ML, and Deep Learning
- Types of Machine Learning
- Python Fundamentals for ML
- Data Collection, Cleaning, and Preprocessing
- Exploratory Data Analysis (EDA)
- Statistics, Probability, and Linear Algebra
- Regression and Classification Algorithms
- Model Evaluation and Validation
- Clustering Techniques
- Dimensionality Reduction using PCA
- Neural Networks and Backpropagation
- TensorFlow and PyTorch
- Computer Vision
- Natural Language Processing (NLP)
- Model Deployment and Final Project
