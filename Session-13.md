# Session 13: Introduction to Regression in Machine Learning

## Topics Covered
- Introduction to Regression.
- Types of Regression.
- Independent and Dependent Variables.
- Real-world applications of Regression.

## Key Learnings

- **Regression:** A supervised Machine Learning technique used to predict continuous numerical values.
- **Independent Variables:** Input features used by the model to make predictions.
- **Dependent Variable:** The target value that the model aims to predict.
- **Linear Regression:** Models the relationship between input features and a continuous output using a linear equation.
- **Multiple Regression:** Uses two or more input features to predict an output.
- **Regression Applications:** Used for house price prediction, sales forecasting, and temperature estimation.

## Important Concepts
- Regression learns relationships between input features and target values.
- Training data helps the model learn patterns.
- Testing data evaluates predictions on unseen examples.
- Common evaluation metrics include MAE, MSE, RMSE, and R² Score.

## Key Takeaways
- Regression is mainly used to predict continuous numerical values.
- Input features influence the predicted output.
- Choosing relevant features helps improve model performance.
- Evaluation metrics measure the difference between actual and predicted values.
